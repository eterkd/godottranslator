# godottranslator
godot auto translator

포함된 요소
node_GoogleTranslator_server
mod_load.gd
mod_translation.pck
override.cfg
readme.txt

자동 변역할 게임 폴더에 위 파일과 폴더를 복사한다.(node_GoogleTranslator_server 경우 다른곳에서 두고 실행해도 됨)
node_GoogleTranslator_server폴더에 있는 start_GoogleTranslator_server.cmd를 실행후 게임을 실행한다.

번역 스크립트가 정상적으로 구동 되었다면 Translation폴더가 생기고 캐시파일과 config.ini파일이 만들어진다.

일부 고도 엔진 게임에 대응 못할수도 있음. 고도 엔진 4.0 ~ 4.6까지 대응 될것으로 보임
